# 玩法 A《糖果锦鲤池》RTP 报告

> 本文数字全部来自 `sim/summary_A_*_final.json`(蒙特卡洛)与 `sim/analytic.json`(精确枚举 + DP),由 `scripts/makeReport.ts` 生成。

## 1. 模拟设置(可复现)

- 配置:`config/gameA.ts`(version `1.1-math-r1`),引擎协议 v2,模拟走 `engine.playRound`(= 循环 `step` 至整局结束),固定投注 bet=100。
- 正常游玩:**200,000,000 局**,8 个 shard(seed `final-A-normal-1` … `final-A-normal-8`),每 shard 25 批,共 200 批(每批 1,000,000 局)。
- 购买:**20,000,000 次**,8 个 shard(seed `final-A-buy-1` … `final-A-buy-8`),共 200 批(每批 100,000 次)。
- 复现:`bash scripts/finalSim.sh && bash scripts/finalMerge.sh`(全部 4 组;单组如 `bash scripts/runSim.sh A normal 200000000 8 final 25 && node --import tsx scripts/merge.ts A normal final`)。原始分批结果:`sim/raw/A_{normal,buy}_final_{1..8}.json`;汇总:`sim/summary_A_{normal,buy}_final.json`;解析交叉检验:`sim/analytic.json`(`npx tsx scripts/analyticReport.ts`)。
- 置信区间:分批估计标准误 SE = sd(批 RTP)/√批数,95% CI = RTP ± 1.96·SE;括号内为由每局赢额方差得到的解析 SE 作交叉检验。

## 3. 波动性与上限

- 每局赢额标准差(倍总投注)= 5.684;波动性指数(95% 置信,1.96·σ,单位:投注)= 11.14。
- 最大赢额 = 845.4x 总投注(正常)/ 947.1x(购买);5000x 上限触达 0 局(正常)/ 0 次(购买)。上限截断造成的 RTP 损失(模拟内累计)= 0.0000%。
- 本样本中未出现 5000x 上限与 60 次 FS 上限的真实触达;这两条规则由单元测试(构造轴带)覆盖,且解析值(不含上限)与模拟值一致,说明上限对 RTP 的影响低于模拟分辨率。

## 4. 购买 Free Spins

- 购买价格:**48x** 总投注(文档初值 75x;解析使购买 RTP = 正常 RTP 的价格为 48.041x)。
