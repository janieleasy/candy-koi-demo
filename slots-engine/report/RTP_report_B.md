# 玩法 B《金鲤满仓》Hold & Spin RTP 报告

> 本文数字全部来自 `sim/summary_B_*_final.json`(蒙特卡洛)与 `sim/analytic.json`(精确枚举 + 马尔可夫链),由 `scripts/makeReport.ts` 生成。

## 1. 模拟设置(可复现)

- 配置:`config/gameB.ts`(version `1.1-math-r1`),引擎协议 v2,模拟走 `engine.playRound`(= 循环 `step` 至整局结束),固定投注 bet=100。
- 正常游玩:**400,000,000 局**,8 个 shard(seed `final-B-normal-1` … `final-B-normal-8`),每 shard 25 批,共 200 批(每批 2,000,000 局)。
- 购买:**40,000,000 次**,8 个 shard(seed `final-B-buy-1` … `final-B-buy-8`),共 200 批(每批 200,000 次)。
- 复现:`bash scripts/finalSim.sh && bash scripts/finalMerge.sh`(全部 4 组;单组如 `bash scripts/runSim.sh B normal 400000000 8 final 25 && node --import tsx scripts/merge.ts B normal final`)。原始分批结果:`sim/raw/B_{normal,buy}_final_{1..8}.json`;汇总:`sim/summary_B_{normal,buy}_final.json`;解析交叉检验:`sim/analytic.json`(`npx tsx scripts/analyticReport.ts`)。
- 置信区间:分批估计标准误 SE = sd(批 RTP)/√批数,95% CI = RTP ± 1.96·SE;括号内为由每局赢额方差得到的解析 SE 作交叉检验。

## 3. 波动性与上限

- 每局赢额标准差(倍总投注)= 9.961;波动性指数(95% 置信,1.96·σ,单位:投注)= 19.52。
- 最大赢额 = 2187.0x 总投注(正常)/ 2232.0x(购买);10000x 上限触达 0 局(正常)/ 0 次(购买)。上限截断造成的 RTP 损失 = 0.0000%。
- 10000x 上限在本样本中未被触达(满屏 + 多个 Grand 币的极端组合概率低于模拟分辨率);该规则由单元测试(构造 Grand 币)覆盖。

## 4. 购买 Hold & Spin

- 购买价格:**85x** 总投注(文档初值 60x;解析使购买 RTP = 正常 RTP 的价格为 85.010x)。
- 购买 RTP:**96.017%**(95% CI 95.987% ~ 96.046%;解析值 96.014%);平均赢额 81.614x 投注,平均最终 K 10.738,满屏 1/513.4 每次购买(占 0.1948%),Jackpot 合计(含满屏)占 RTP 8.523%。
- **购买 RTP − 正常 RTP = -0.007 个百分点**(差值 SE ≈ 0.055 pp);要求 ≤ 0.5 pp → 达标。
- 购买局波动(相对购买价):σ = 0.904x 价格。

## 6. 说明

- **Jackpot 口径**:文档第 0 节「Jackpot 四层合计 4%~7%」,本报告把满屏 Grand 奖励算作 Grand 层级奖金,故「合计 = Jackpot 币 + 满屏 Grand」。若只统计 Jackpot 币,为 3.987%(略低于 4%);请策划确认口径。
- 命中率口径:基础旋转线赢 > 0(B 无 Scatter;触发 H&S 但无线赢的旋转不计为命中)。
- H&S 的赢额只在结算步一次发放;表中「H&S 贡献」= 特色玩法赢额(含截断后),与基础线赢相加等于总 RTP。
