# 产品页 A|《糖果锦鲤池》(Candy Koi Pond)

> 5 轴 3 行 · 20 条固定线 · Free Spins + 连赢倍数阶梯 · 中高波动 · 规则 v1.2 / 数学配置 `1.1-math-r1`

## 1. 定位与目标玩家
- **定位**:最容易让人一眼看懂的经典线赢结构(5x3、20 线、左到右连线),叠加一个有节奏感的特色玩法。糖果风锦鲤主题,厚描边、3D 果冻质感,偏手游/社交赌场;不使用宗教符号,不出现龙。
- **目标玩家**:喜欢经典老虎机、想要"清楚规则 + 可感知爽点"的休闲到进阶玩家;同时是面试官/评审友好的演示玩法(规则少,逻辑可逐条验证)。
- **波动性**:中高。每局赢额标准差 5.684x 总投注;波动性指数(1.96σ)11.14。

## 2. 核心循环
1. 选投注档位 → 旋转;20 线全开,仅左到右,3 连起赔,Wild(彩虹珍珠,只在第 2/3/4 轴)可替代除糖果门外的图案。
2. **糖果门**(糖果拱门)任意位置出现 ≥3 个触发 Free Spins:3/4/5 个送 **8/12/20** 次;糖果门赢额 2/10/50x 总投注。
3. Free Spins 内**连赢倍数阶梯 x1→x2→x3→x5**:有线赢则升一档,无线赢则回 x1;只加倍线赢,糖果门赢额不乘。
4. FS 内再出 ≥3 个糖果门重触发,追加 **5/8/12** 次,单局累计最多 **60** 次;整局结算后回到基础游戏。
5. **本玩法没有连消(cascade)**,"连赢倍数阶梯"是唯一的连续增益机制。

## 3. 关键数值与设计取舍
| 指标 | 数值(来源:RTP_report_A) |
|---|---|
| 总 RTP | **95.963%**(95% CI 95.887%~96.039%;解析值 95.999%;目标 96.0%,区间 95.5%~96.5%) |
| 基础贡献 / FS 贡献 | 64.980%(线赢 63.399% + 糖果门 1.581%)/ **30.983%** |
| 基础命中率 | 28.995%;零赢局 71.005% |
| FS 触发频率 | 0.6521% = **1/153.3**;平均每次触发实际 FS 次数 8.4207 |
| 最高赢取上限 | 5000x 总投注(样本最大赢额 845.4x,正常游玩 2 亿局未触顶) |
| 模拟规模 | 正常 200,000,000 局 + 购买 20,000,000 次,并有精确枚举/DP 解析值交叉检验 |

**取舍要点**
- **倍数阶梯是 FS 的价值核心**:x5 档只占 FS 旋转的 23.918%,却贡献 14.759% RTP(x1 档:36.640% 旋转 / 4.521% RTP)。这就是"越连越爽"的数值来源。
- **FS 轴带更"肥"但不加触发**:FS 轴带 Wild 占比 14.44%(BASE 6.06%),低图案 43.33%(BASE 48.48%),糖果门占比 2.78% ≤ BASE 的 3.03%,以此控制重触发。
- **整数赔付、无 2 连赔付**:全部赔付为整数倍数,保证钱数为整数最小货币单位;赔付表数值在数学校准中**未改动**。

### ★ 亮点:购买价为何从 75x 调整为 48x
| | 建议价 75x | 最终价 48x |
|---|---|---|
| 购买 RTP | 约 **61.5%**(与正常游玩差约 34 pp) | **96.083%**(95% CI 96.048%~96.118%) |
| 与正常游玩(95.963%)之差 | 远超 ≤0.5 pp 要求 | **+0.120 pp**(达标) |

- 原因:购买 = 直接送 8 次 FS,期望赢额仅约 **46.12x** 总投注(阶梯从 x1 起步、且按最少的 3 个糖果门起步,不付触发时的糖果门赢额)。75x 买一份 ≈46x 的期望,对玩家明显不公平。
- 方法:按"购买 RTP = 正常 RTP"反解,精确等 RTP 价为 48.041x,取整数 **48x**。价格由 `config.buy.priceMult` 读取,界面不写死。
- 产品提醒(数学报告原话要点):48x 仅是基础旋转平均成本的 48 倍,而自然触发率为 1/153.3,**该价格需产品/合规最终确认**。

## 4. 风险与合规要点
1. **购买功能(Buy Feature)在真钱市场可能不被允许**:演示版开启(`BUY_FEATURE_ENABLED = true`)并强制显示"购买功能仅为演示。在部分真钱市场该功能可能不被允许。";真钱构建默认关闭,由合规决定。
2. **演示用 RNG 不可直接用于真钱**:演示用引擎内置 RNG(可设种子复现,调试开关 `?seed`),真钱必须换用经认证的 RNG,并按目标市场重新做 RTP 认证。
3. **上限与未覆盖项**:5000x 上限、60 次 FS 上限在真实配置的模拟中均未触达,靠构造轴带的单元测试覆盖;上线前需对极端组合再做认证级验证。
4. **数字口径**:RTP 为蒙特卡洛 + 解析验证的结果,赔付参数 `[数学可调]` 范围内的任何改动都需重跑模拟;演示币无真实价值,余额可重置为 10000 演示币。
