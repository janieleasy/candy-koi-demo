# 产品页 B|《金鲤满仓》(Hold & Spin)

> 5 轴 3 行 · 10 条固定线 · 锁定符号 Hold & Spin · 四层固定倍数 Jackpot · 高波动 · 规则 v1.2 / 数学配置 `1.1-math-r1`

## 1. 定位与目标玩家
- **定位**:规则极简的"锁币 + 重置计数"紧张感玩法。基础游戏只有 10 线、3 连起赔,**无 Wild、无糖果门**;所有戏剧性集中在 Hold & Spin。与玩法 A 同主题、复用同一批符号素材。
- **目标玩家**:追求高波动、"差一点满屏"刺激感、愿意用大部分时间等一次特色玩法的进阶玩家;对评审而言,锁定 + 重置 R=3 的节奏好讲、好验证。
- **波动性**:高。每局赢额标准差 9.961x 总投注;波动性指数(1.96σ)19.52;零赢局 76.302%。

## 2. 核心循环
1. 基础旋转:10 线、左到右、至少 3 连;金币锦鲤(C)可出现在任意格,不参与连线。
2. 15 格内 C ≥ 6 触发 Hold & Spin:C 锁定,其余格变空,**剩余重旋转次数 R = 3**。
3. 每次重旋转只转空格:有新 C 落下则锁定并 **R 重置为 3**(不是累加);一个都没有则 R 减 1。
4. R 减到 0 或 15 格全满即结算。币值为 1/2/3/5/8/10/15/25/50 倍总投注;重旋转中还可能出 Jackpot 币。
5. **满屏 15 个 C 额外获得一次 Grand(1000x)**,叠加在所有锁定币价值之上。

## 3. 关键数值与设计取舍
| 指标 | 数值(来源:RTP_report_B) |
|---|---|
| 总 RTP | **96.023%**(95% CI 95.921%~96.126%;解析值 96.003%;目标 96.0%,区间 95.5%~96.5%) |
| 基础线赢 / H&S 贡献(含 Jackpot) | 32.976% / **63.047%**(倍数币 57.527%) |
| 基础命中率 | 22.997% |
| H&S 触发频率 | 0.7785% = **1/128.4**;每次 H&S 平均最终 K = 10.733,平均重旋转 7.638 次 |
| 最高赢取上限 | 10000x 总投注(样本最大赢额 2187.0x,4 亿局未触顶) |
| 模拟规模 | 正常 400,000,000 局 + 购买 40,000,000 次,并有精确枚举/马尔可夫链解析值交叉检验 |

**四层 Jackpot(含满屏 Grand)——全部为总投注的固定倍数**
- 倍数:Mini 10x / Minor 25x / Major 100x / Grand 1000x。
- 合计贡献 **5.520%** RTP(目标 4%~7%):Mini 0.556% + Minor 0.648% + Major 0.939% + Grand 1.843% + 满屏 Grand 1.533%。
- 其中仅 Jackpot 币为 3.987%(约 3.99%),**略低于 4%**——口径已统一为"四层含满屏 Grand",数学报告建议策划确认。
- 稀有度:Grand 币 1/54296.2 局;满屏 1/65231.6 局(占 H&S 的 0.1969%);Mini 1/1855.4 局。

**取舍要点**
- **p(K) 随锁定数递减**(K=6→14:0.1808 → 0.0242,严格单调、均在 0~1 内),保证"越满越难";满屏概率由 p(14)=0.0242 调出。
- **Jackpot 币只在重旋转中出现**(每个新 C 以 q = 0.026 成为 Jackpot 币),起手 C 只能是倍数币,便于控制数学。
- **赔付表、币值集合、Jackpot 倍数在校准中均未改动**,数学只调了权重、p(K)、q 与轴带。

### ★ 亮点:购买价为何从 60x 调整为 85x
| | 建议价 60x | 最终价 85x |
|---|---|---|
| 购买 RTP | 约 **136%**(玩家每次购买都是明显正期望) | **96.017%**(95% CI 95.987%~96.046%) |
| 与正常游玩(96.023%)之差 | 远超 ≤0.5 pp 要求 | **-0.007 pp**(达标) |

- 原因:购买(恒为 6 个起始倍数币)期望赢额约 **81.61x** 总投注(模拟 81.614x),60x 买入等于送钱。
- 方法:按"购买 RTP = 正常 RTP"反解,精确等 RTP 价为 85.010x,取整数 **85x**,价格由 `config.buy.priceMult` 读取。
- 与玩法 A 方向相反(A 下调、B 上调),说明两个玩法的购买价必须**各自校准**,不能凭直觉定价。

## 4. 风险与合规要点
1. **购买功能(Buy Feature)在真钱市场可能不被允许**:演示版开启并强制显示"购买功能仅为演示。在部分真钱市场该功能可能不被允许。";真钱构建默认关闭,由合规决定。
2. **演示用 RNG 不可直接用于真钱**:真钱需使用经认证的 RNG,并按目标市场重新认证 RTP。
3. **Jackpot 为固定倍数,不是累进奖池**:界面 Jackpot 牌显示"层级倍数 x 当前投注",不需要后端奖池累积;文案不得暗示奖池会增长。
4. **极端尾部**:10000x 上限在模拟中未触达(满屏 + 多个 Grand 币的极端组合概率低于模拟分辨率),靠构造 Grand 币的单元测试覆盖;>1000x 的赢额占 0.0034% 的局,高波动玩法需配套负责任博彩提示。
