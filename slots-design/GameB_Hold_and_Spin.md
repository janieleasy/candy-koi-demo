# 玩法 B 规则文档:《金鲤满仓》Hold & Spin(5 轴 3 行 + 锁定符号 + 四层 Jackpot)

版本 v1.2(购买价对齐数学配置) / 作者:玩法策划 / 读者:数学/数值、游戏工程师
约定:标注 [数学可调] 的数值由数学校准,其余为硬规则。主题与玩法 A 同为「糖果锦鲤池」,复用同一批符号素材。

---

## 0. 定位与设计理由(供产品文档引用)

- 主题:糖果锦鲤池。特色玩法里,"金币锦鲤"游到糖果池塘中锁定,像鱼群聚集。
- 玩法:5 轴 3 行、15 格。基础游戏为 10 条固定线、从左到右 3 连起赔(无 Wild、无 Scatter,规则最少);触发 Hold & Spin 后进入锁定加重旋转的特色玩法。
- 波动性:高。
- 目标 RTP:总 RTP 96.0%,区间 95.5% 到 96.5%。
  - 基础游戏线赢约 30% 到 36%。
  - Hold & Spin 特色玩法(含 Jackpot)约 60% 到 66%。
  - 其中 Jackpot 四层合计贡献约 4% 到 7%。
- 基础游戏命中率:20% 到 26%。
- Hold & Spin 触发频率:约 1/100 到 1/160 次旋转。
- 最高赢取上限:单局 10000 倍总投注。
- 设计理由:
  1. 锁定加重旋转 3 次,规则极少,玩家一看就懂,适合网页 demo 演示"紧张感"。
  2. 重置计数让每次新增符号都带来希望,是面试时好讲的节奏设计。
  3. 四层固定倍数 Jackpot(Mini、Minor、Major、Grand)清晰,且全部是对总投注的固定倍数,不需要后端累积奖池,真钱和演示都能直接用。
  4. 满屏 15 个符号直接得 Grand,是明确的终极目标。

### 3.1 10 条赔付线

行号:1 = 上行,2 = 中行,3 = 下行。

| 线 | 轴1 | 轴2 | 轴3 | 轴4 | 轴5 |
|---|---|---|---|---|---|

### 3.2 线赢判定(逐线)

对每条线取 c[1..5]:
1. 若 c[1] 是 C,该线不赢。
2. X = c[1];n = 1;从 i = 2 到 5:若 c[i] == X 则 n = n + 1,否则停止。(无 Wild,所以只比较相等。)
3. 若 n >= 3,赢额 = 赔付表[X][n] x 线投注;否则 0。
4. 10 条线赢额相加。

## 4. 特色机制:Hold & Spin

### 4.1 触发

- 条件:基础游戏一次旋转后,15 格可见区域内 C 的数量 >= 6。
- 与线赢关系:同一旋转的线赢先入账,再进入 Hold & Spin。
- C 的数量 6 到 15 都触发,起始符号就是这些 C(见 4.2)。
- 触发后无需玩家操作,自动进入。

### 4.2 进入时的状态

1. 当前可见区域上的所有 C 变为**锁定**(Locked),位置和币值不再变化。
2. 其余格子变为**空格**(Empty,可再旋转)。
3. 剩余重旋转次数 R = 3。
4. 计数器显示:已锁定数量 K、剩余重旋转次数 R。

### 4.3 重旋转(Respin)流程,每一次重旋转

1. 只有空格参与旋转,锁定格不动。
2. 对每个空格,独立以概率 p(K)(见 5.3)决定是否落下一个新的 C。落下时由 RNG 决定币值或特殊值(见 5.1)。
3. 若本次重旋转有至少 1 个新 C 落下:新 C 立刻锁定,R 重置为 3。
4. 若本次一个新 C 都没有落下:R = R - 1。
5. 若 R == 0 或 15 格全满,Hold & Spin 结束,进入结算(见 4.5)。
6. 否则继续下一次重旋转。

注意:R 的重置总是回到 3,不是累加。第一次重旋转开始时 R 已经是 3。

### 4.4 锁定符号的币值

C 的值有两类:

(a) 倍数币:值是总投注的整数倍数 v,取自币值表(见 5.1)。
(b) Jackpot 币:值是 Jackpot 层级标签 Mini / Minor / Major / Grand 之一,出现概率很低。

- Jackpot 币**只在 Hold & Spin 内的重旋转中出现**,触发时的起始 C(来自基础游戏)只能是倍数币。理由:避免基础游戏直接起手就带 Jackpot,让数学更好控制。
- Hold & Spin 期间没有任何符号会移动、消失、合并,也没有额外的"收集者"符号,保持规则最小。

### 4.5 结算

Hold & Spin 结束时,对所有锁定的 C 求和:

- 倍数币:赢额 += v x 总投注。
- Jackpot 币:按下表,赢额 += 层级倍数 x 总投注。每个 Jackpot 币独立计算,可以同时出现多个。

| Jackpot 层级 | 倍数 [数学可调] |
|---|---|
| Mini | 10 |
| Minor | 25 |
| Major | 100 |
| Grand | 1000 |

- 满屏奖励:若结束时 15 格全部为 C,额外获得 Grand 奖励 1 次(层级倍数 1000 x 总投注),**叠加**在所有锁定 C 的价值之上。该奖励不依赖是否出现过 Grand 币。
- 倍数 v 与 Jackpot 倍数都是整数倍总投注。

## 5. 数值生成规则(给数学)

### 5.1 币值表 [数学可调]

倍数币 v 从下表按权重抽取(权重由数学决定,下表为建议的取值集合):

v ∈ {1, 2, 3, 5, 8, 10, 15, 25, 50}(单位:总投注倍数)

- 币值集合必须全为整数。
- 基础游戏起始 C 与 Hold & Spin 内新 C 可以使用不同权重表(建议后者略高),由数学决定。
- Jackpot 币在 H&S 内以独立概率出现:每个新 C 落下时,以概率 q 成为 Jackpot 币(q 由数学定),再按层级权重决定 Mini/Minor/Major/Grand,Grand 币最稀有。

### 5.2 基础游戏卷轴带

- 基础游戏使用一组 5 条卷轴带,每个格子的 C 出现由卷轴带上的 C 位置决定。
- 每条卷轴带上 C 的数量由数学配置。触发 >= 6 个 C 的频率目标见第 0 节。

### 5.3 重旋转落 C 概率 p(K)

- p(K) 是「已锁定 K 个时,每个空格出现新 C 的概率」,[数学可调]。
- 约束:
  1. p(K) 单调不增(K 越大,p 越小或相等),保证越满越难。
  2. 0 < p(K) < 1。
  3. K >= 14 时(只剩 1 格),p(14) 应使满屏概率符合第 0 节 Grand 贡献目标。
- 工程实现:p 查表,下标是 K(6 到 14),数学提供数组。
- 每个空格各自独立判定,一次重旋转内可以同时落下多个 C。

## 6. 边界情况(逐条判定)

| 场景 | 规则 |
|---|---|
| 基础旋转 C 数量恰好 5 | 不触发。C 只是中断连线,不赔付 |
| 基础旋转 C >= 6 且同时有线赢 | 线赢先入账,然后进入 H&S |
| 起始就有 15 个 C | 直接进入结算:不进行任何重旋转,满屏奖励生效 |
| 重旋转中同时落下多个 C | 全部锁定,R 重置为 3 仅一次 |
| 重旋转落下的 C 恰好使 15 格全满 | 立即结束并结算,不再进行重旋转 |
| R 减到 0 | 立即结束,不再进行额外重旋转 |
| 一次重旋转没有新 C,但 R 仍大于 0 | R 减 1 后继续 |
| 满屏奖励与 Grand 币 | 可叠加:Grand 币价值加满屏 Grand 奖励 |
| 单局累计赢额 >= 10000 x 总投注 | 截断为上限,立即结束并结算(包括 H&S 剩余次数作废),提示「已达最高赢取」。因为 H&S 的赢额只在结算时发放,截断发生在 4.5 的求和之后(总额超过上限则取上限) |
| 刷新页面或断线 | 必须恢复:所有锁定格的位置和币值、R、K、本局累计线赢、总投注。每次重旋转结算后保存状态 |
| 结果生成 | 每次(重)旋转结果在请求时由 RNG 一次生成;动画/跳过不影响结果 |
| 自动旋转 | H&S 触发时暂停,结算后可继续 |
| Hold & Spin 内改变投注 | 不允许。H&S 期间使用触发时的总投注 |
| 余额 | H&S 期间不扣费 |

## 8. 界面与动画规则(已确认展示 K/R 计数器与币值飞入)

以下只定义「显示什么、何时更新」,动效细节由 UI 决定,不影响结算结果。

### 8.1 K/R 计数器
- 显示内容:剩余重旋转次数 R(用 counters/dots_0of3 到 dots_3of3 的三点灯,亮点数 = R),以及已锁定数量 K(文字「K / 15」)。
- 更新时机:
  1. 进入 H&S:R = 3(三点全亮),K = 起始 C 数量。
  2. 每次重旋转停轴后:有新 C 则 K 增加、R 回到 3(三点重新点亮);无新 C 则 R 减 1(熄灭一个点)。
- 只有在停轴动画结束后才更新,不得先于符号显示。

### 8.2 币值飞入动画
- 触发:H&S 结算开始时。
- 顺序:按轴 1 到轴 5、每轴从上到下的顺序,逐个锁定的 C 将币值数字飞入顶部赢额条(win-bar),赢额条数字累加。
- Jackpot 币飞入时,同时点亮 jackpot-bar 上对应层级牌,并累加该层级倍数。
- 若满屏,所有锁定 C 飞入完毕后再播放满屏 Grand 奖励。
- 动画可被「跳过」,跳过后直接显示最终赢额,金额不变。
- 动画顺序不影响金额,金额以第 4.5 节为准。

## 9. 演示版附加规则

### 9.1 演示币与重置余额
- 默认余额 10000 演示币。菜单(btn-menu)提供「重置余额」,确认后恢复为 10000。
- 重置只在基础游戏空闲状态可用;旋转中、H&S 进行中、购买确认中置灰。
- 余额不足以支付最小投注档位时,旋转按钮置灰并提示重置余额。

### 9.2 投注档位
- 每个总投注必须能被 10 整除。建议演示币档位:10、20、50、100、200、500。
- H&S 期间投注加减、最大投注置灰。

## 10. 自动旋转规则(保留)

1. 可选次数:10、25、50、100,另可选「直到特色玩法触发」。
2. 每次旋转前校验余额 >= 总投注,不足则停止。
3. 触发 Hold & Spin、玩家点击停止、余额不足、玩家调整投注时,自动旋转停止并回到关闭状态;H&S 结束后需玩家重新开启。
4. 结果生成与手动旋转完全一致。
