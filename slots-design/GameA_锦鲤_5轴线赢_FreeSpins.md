# 玩法 A 规则文档:《糖果锦鲤池》5 轴 20 线 + Free Spins

版本 v1.2(购买价对齐数学配置、Scatter 改名「糖果门」) / 作者:玩法策划 / 读者:数学/数值、游戏工程师
约定:本文所有赔付数字均为「初始建议值」,标注 [数学可调] 的由数学校准,但必须遵守该条标注的约束。未标注的规则为硬规则,不得改动。

---

## 0. 定位与设计理由(供产品文档引用)

- 主题:糖果风锦鲤池(Candy Koi Pond)。金色锦鲤、棒棒糖灯笼、软糖莲花、太妃糖元宝,厚描边、3D 果冻糖果质感,偏手游/社交赌场,不使用任何宗教符号,也不出现龙。
- 玩法:5 轴 3 行、20 条固定赔付线、左到右连线赢,加 Free Spins 与连赢倍数阶梯。
- 波动性:中高。
- 目标 RTP:总 RTP 96.0%,可接受区间 95.5% 到 96.5%。
  - 基础游戏贡献约 62% 到 68%。
  - Free Spins 贡献约 28% 到 34%。
- 基础游戏命中率(任意线赢或 Scatter 赢):26% 到 32%。
- Free Spins 触发频率:约 1/120 到 1/180 次旋转。
- 最高赢取上限:单局 5000 倍总投注。
- 设计理由:
  1. 20 线 5x3 是最容易让面试官一眼看懂的经典结构。
  2. Free Spins 里加「连赢倍数阶梯」,让特色玩法有可感知的节奏和爽点,同时规则只有几条,代码容易判定。
  3. 触发图案 Scatter 用「任意位置」判定,避免玩家对触发条件产生歧义。
  4. 复赢与上限都写成硬规则,方便合规审核(真钱市场需要明确的最大赢额)。

## 1. 基础参数

| 项目 | 规则 |
|---|---|
| 轴数 x 行数 | 5 轴 x 3 行,共 15 个格子 |
| 赔付线 | 20 条固定线,始终全部激活,玩家不能选择线数 |
| 总投注 | 玩家选择的投注档位(Total Bet) |

| 单局 | 一次基础旋转,加上它触发的整段 Free Spins,合称一局(Round)。结算在整局结束后入账,过程中显示累计 |

### 2.1 Wild 规则

1. W 只会出现在第 2、3、4 轴(由卷轴带配置保证,引擎不需要额外判定)。
2. W 可替代除 S 以外的所有图案。
3. W 没有独立赔付。由于 W 不会出现在第 1 轴,一条线的第 1 格永远不是 W,所以不存在「纯 W 连线」。
4. W 不能替代 S。

### 2.2 Scatter 规则

1. S 可出现在 1 到 5 轴。
2. S 不参与连线,也不会被 W 替代。落在赔付线上的 S 会中断该线的连线(因为它不等于任何线图案,也不是 W)。
3. S 按「整个 15 格可见区域内的 S 数量」计算,与位置无关。
4. 每轴在可见 3 行内最多出现 1 个 S(由卷轴带间距保证,见 6.3),因此一次旋转的 S 数量为 0 到 5。

## 5. 线赢判定算法(逐线,可直接转代码)

对每条线,取该线上的 5 个格子,按轴 1 到轴 5 排成序列 c[1..5]:

1. 若 c[1] 是 S,该线不赢,结束。(c[1] 不可能是 W。)
2. 令 X = c[1]。
3. 令 n = 1。从 i = 2 到 5:若 c[i] == X 或 c[i] == W,则 n = n + 1;否则停止。
4. 若 n >= 3,该线的赢额 = 赔付表[X][n] x 线投注。否则 0。
5. 每条线只取一个赢额(即该线上从轴 1 起的最长连续)。

补充规则:
- 线赢相加:20 条线的赢额逐条相加。
- 同一条线不会同时算「3 连」和「4 连」,只算最长的那一个。
- 不同赔付线可以共用同一格子,各自独立计算,不去重。
- 因为 X 永远等于 c[1],而 W 不在轴 1,所以不存在「以 W 开头」的判定问题。
- Free Spins 中的线赢要乘以倍数阶梯(见 7.4);Scatter 赢不乘。

## 6. 卷轴与随机规则(给数学与工程)

### 6.1 卷轴带

- 基础游戏使用一组 5 条卷轴带(BASE 卷轴带),Free Spins 使用另一组 5 条卷轴带(FS 卷轴带)。
- 每轴停止位置由 RNG 在该轴带长度内均匀随机选取,可见 3 行为连续 3 个位置(轴带首尾相接,循环)。
- 卷轴带具体排列与长度由数学提供,必须满足 6.2 与 6.3。

### 6.2 图案分布硬约束

1. W 只出现在轴 2、3、4 的卷轴带中。
2. 轴 1 与轴 5 的卷轴带中没有 W。
3. S 可出现在所有 5 条轴带中。

### 6.3 S 的间距约束

每条卷轴带上任意相邻 3 个位置内最多只有 1 个 S,保证可见 3 行内同一轴最多出现 1 个 S。

### 6.4 FS 卷轴带差异 [数学可调]

FS 卷轴带相对 BASE 卷轴带:W 更多,低图案更少。具体权重由数学决定,但 FS 卷轴带上 S 的比例不得高于 BASE,以控制重触发频率。

## 7. 特色机制:Free Spins

### 7.1 触发

- 条件:基础游戏的一次旋转后,可见 15 格内 S 数量 >= 3。
- 与线赢的关系:同一旋转的线赢与 Scatter 赢先入账(显示累计),再进入 Free Spins。
- 赠送次数:

| S 数量 | 赠送 Free Spins 次数 |
|---|---|
| 3 | 8 |
| 4 | 12 |
| 5 | 20 |

### 7.2 Free Spins 中的投注

- 每次 Free Spin 的投注 = 触发它的那次基础旋转的总投注。Free Spins 期间不允许改投注,也不扣费。

### 7.3 重触发

- 条件:Free Spins 中某次旋转后,可见 15 格内 S 数量 >= 3。
- 追加次数:

| S 数量 | 追加 Free Spins 次数 |
|---|---|
| 3 | 5 |
| 4 | 8 |
| 5 | 12 |

- 单局累计上限:一局内(初始赠送加所有追加)最多 60 次 Free Spins。若追加会超过 60,则只追加到 60 为止(多余的作废)。S 的 Scatter 赢仍然照常支付,不受上限影响。
- 已达 60 次上限后再次出现 >= 3 个 S:不追加,但仍然支付 Scatter 赢。
- 重触发不需要玩家额外操作。

### 7.4 连赢倍数阶梯

- 倍数阶梯表:M = [1, 2, 3, 5],下标 c 取 0 到 3。
- 状态:Free Spins 开始时 c = 0(第一次 Free Spin 倍数为 x1)。
- 剩余次数在每次 Free Spin 开始时先减 1,重触发的追加次数在该次旋转结算时加入。
- 每次 Free Spin 的结算顺序:
  1. 旋转,得到可见区域。
  2. 倍数 m = M[c]。
  3. 计算线赢总额 L。实际入账的线赢 = L x m。
  4. 计算 Scatter 赢(不乘倍数)。
  5. 重触发判定(见 7.3)。
  6. 更新阶梯:若 L > 0,则 c = min(c + 1, 3);否则 c = 0。判定只看线赢 L,Scatter 赢不算。所以只有 Scatter 赢而没有线赢的那一次,c 重置为 0。
  7. 检查上限(见 9.1)。
- 重触发不重置阶梯,阶梯在整个 Free Spins 内连续。
- Free Spins 结束后阶梯清零,不带回基础游戏。

### 7.5 结束

- 剩余次数为 0 且无待追加次数时,Free Spins 结束,整局结算入账,回到基础游戏。

## 8. 购买 Free Spins(BUY_FEATURE_ENABLED)

- 演示版:BUY_FEATURE_ENABLED = true(已确认开启)。
- 界面说明文字(必须在购买入口或帮助页显示):「购买功能仅为演示。在部分真钱市场该功能可能不被允许。」
- 真钱构建:默认 BUY_FEATURE_ENABLED = false,由合规决定。
- 价格:48 x 总投注(取自数学配置 `slots-engine/config/gameA.ts` 的 `buy.priceMult`,以该配置为准)。购买模式 RTP 与正常游玩相差不超过 0.5 个百分点。
- 购买流程:
  1. 玩家点击购买,弹出确认框,显示价格。
  2. 确认时校验余额 >= 价格,否则确认按钮不可点。
  3. 扣除价格,直接赠送 8 次 Free Spins(相当于 3 个 S 触发),不进行基础旋转,不支付触发时的 Scatter 赢。
  4. 购买局内,重触发、倍数阶梯、60 次上限、5000x 上限的规则与正常触发完全一致。
- 5000x 上限的参照总投注 = 购买时的总投注(不是购买价格)。

## 9. 边界情况(逐条判定)

### 9.1 单局最高赢取上限

- 上限 = 5000 x 总投注(含基础旋转赢额、所有 Free Spins 赢额、Scatter 赢)。
- 当累计赢额 >= 上限:累计赢额截断为上限,当前旋转结算完毕后,立即结束整局,剩余 Free Spins 作废。界面提示「已达最高赢取」。
- 截断只发生在每次旋转结算的第 7 步,不会在一次旋转内部拆分。

### 9.2 其他

| 场景 | 规则 |
|---|---|
| 同一旋转中既有线赢又有 Scatter 赢 | 两者相加。Free Spins 中线赢乘倍数,Scatter 不乘 |
| 同一条线上出现 W 加 S | S 中断连线 |
| 线以 S 开头 | 该线不赢 |
| 线上有 W 在中间,两侧是不同图案 | 只按从轴 1 起的图案 X 计算,W 替代 X,遇到不同图案即停止 |
| 3 个 S 恰好落在同一行 | 仍然触发,与位置无关 |
| 基础游戏触发后立刻达到上限 | 不会进入 Free Spins(整局以上限结束) |
| Free Spins 中剩余次数为 0 的同一旋转触发了重触发 | 追加生效,Free Spins 继续 |
| 重触发导致次数超过 60 | 见 7.3,截断到 60 |
| 余额不足以开始一次基础旋转 | 不允许旋转,提示充值/重置 |
| Free Spins 中刷新页面或断线重连 | 必须恢复到断线前一致的状态:剩余次数、阶梯 c、累计赢额、本局投注、已追加总次数。每次旋转结算后都必须落盘/保存状态 |
| 自动旋转 | 保留。规则见 11。遇到 Free Spins 触发时自动旋转暂停并回到关闭状态,Free Spins 结束后需玩家重新开启 |
| 加速/跳过动画 | 只影响动画,不影响结果和结算顺序 |
| 结果生成 | 每次旋转的结果必须在旋转请求时由 RNG 一次生成并确定,不允许根据动画进度改变 |

## 10. 演示版附加规则

### 10.1 演示币与重置余额
- 默认余额:10000 演示币。
- 菜单(btn-menu)内提供「重置余额」:点击后弹出确认框,确认则余额恢复为 10000。
- 重置只在基础游戏空闲状态可用;旋转中、Free Spins 进行中、购买确认中,该入口置灰。
- 余额不足以支付当前最小投注档位时,旋转按钮置灰,并弹出提示引导重置余额。
- 重置不清除统计(旋转次数、累计赢额),只重置余额。

### 10.2 投注档位
- 投注档位列表由数学与产品定,要求每个总投注都能被 20 整除。建议演示币档位:20、40、100、200、400、1000。
- Free Spins 期间,投注加减与最大投注按钮置灰(见素材规范 7)。

## 11. 自动旋转规则(保留)

1. 可选次数:10、25、50、100(产品可调),另可选「直到特色玩法触发」。
2. 自动旋转每次旋转前校验余额 >= 总投注,不足则停止。
3. 以下任一情况停止并回到关闭状态:触发 Free Spins、玩家点击停止、余额不足、玩家调整了投注、单次赢额超过停止阈值(默认关闭该选项)。
4. 自动旋转期间,所有结果仍由 RNG 在每次请求时生成,与手动完全一致。
5. 加速(Turbo)只改变动画速度。
